# OSCA 행사 재생 화면

## 행사 PC에서 실행

1. `OSCA-offline-player.zip`을 폴더째 압축 해제합니다.
2. `index.html`을 Chrome 또는 Edge로 엽니다. Windows에서는 `START_OSCA.cmd`를 더블 클릭해 기본 브라우저로 열 수도 있습니다.
3. 인터넷, 서버, Node.js, 폰트 설치가 필요 없습니다. HTML과 JS, CSS, fonts 폴더를 함께 유지하세요.
4. 상단의 **후보 이름**에서 실제 팀명을 입력합니다. 현재는 원본과 동일하게 후보 1·2·3·4로 표시하며, 소개 문구는 기존 프로젝트의 후보 소개에서 가져왔습니다.
5. 효과음은 기본 꺼짐입니다. 현장 음향 담당자와 확인 후 켤 수 있습니다. 배경음악은 포함하지 않았습니다.

## 진행

- 시상 순서: **O → S → C → A**.
- 모든 부문의 공개 순서: **마곡 → 상암 → 용산 → 온라인 → 수상 후보**.
- 시작 화면 → 부문 후보 소개 → 마곡(10초) → 상암(10초) → 용산(10초) → 온라인(45초) → 수상 연출(7초).
- 각 구간은 자동으로 멈춥니다. 다음 버튼 또는 **→**를 눌러 다음 구간을 공개하세요. 사회자 멘트와 시상 시간 동안 결과 화면을 계속 유지합니다.
- **Space**: 재생/일시정지. 구간 끝에서는 다음 장면.
- **←**: 이전 장면으로 돌아가 정지.
- **F**: 송출 화면만 전체화면. **Esc**: 전체화면 종료.
- 리허설은 2배·4배속과 현재 구간 슬라이더를 사용하세요. 본행사에는 1배속을 선택합니다.
- 탭을 숨기면 재생이 자동으로 멈춥니다. 별도의 송출 창이 열려 있으면 송출 창의 화면 갱신에 맞춰 계속 진행합니다.

## 듀얼 모니터

**송출 창 ↗**을 눌러 새 창을 열고, 그 창을 행사장 모니터로 옮긴 다음 F를 누릅니다. 운영자 창에는 버튼과 다음 멘트 안내가 보이고, 송출 창에는 무대 화면만 보입니다. 팝업이 차단되면 허용하세요. 송출 창의 → / Space도 운영자 창에 전달됩니다. 운영자 창을 닫으면 송출 창도 닫힙니다.

## 후보 이름을 다른 PC로 옮기기

브라우저에서 변경한 이름은 해당 브라우저에 저장됩니다. **후보 이름 → 이름 설정 파일 저장**으로 받은 `config.js`를 행사 폴더의 같은 파일과 교체하면 다른 PC에서도 적용됩니다. 같은 PC의 기존 저장 이름이 있으면 브라우저 저장값이 우선합니다. 이름은 후보 번호와 연결되며 득표 데이터에는 영향을 주지 않습니다.

## 집계와 연출 원칙

오프라인 원본은 제공된 `오스카 오프라인 결과.jpg`이며, 온라인은 `osca_votes_rows.xlsx`의 `osca_votes_rows!A2:C1535` 1,534건입니다. 온라인 원본의 SHA-256은 `votes.js`의 source에 기록되어 있습니다.

S는 후보 4명, 나머지는 3명입니다. 용산 C 4번 1표, 용산 A 4번 10표, 마곡 A 4번 1표를 제외했습니다. 유효 오프라인 6,056표 + 온라인 1,534표 = **7,590표**입니다. 반복 투표는 따로 제외하지 않았습니다.

| 부문 | 후보 1 | 후보 2 | 후보 3 | 후보 4 | 합계 |
| --- | ---: | ---: | ---: | ---: | ---: |
| O | 820 | 656 | 434 | — | 1,910 |
| S | 476 | 491 | 414 | 525 | 1,906 |
| C | 628 | 653 | 610 | — | 1,891 |
| A | 685 | 486 | 712 | — | 1,883 |

오프라인은 사옥별 합계를 동일한 진행률로 더합니다. 중간 프레임은 공개 효과이며 실제 투표 시각을 의미하지 않습니다. 온라인은 원본의 시각순으로 표를 더하며 같은 시각의 표는 함께 반영합니다. 네 부문은 완전히 같은 온라인 시간축을 사용합니다. 표가 없는 공백은 압축하고, 마지막 1/3 구간은 느리게 보여줍니다. 온라인에서 실제 선두 동점·역전이 생기는 순간에는 네 부문 공통 시간축에 짧은 여유를 둡니다. 후보별 표 순서를 바꾸거나 표수를 가공하지 않습니다.

막대 길이는 0부터 시작하며 현재 공개된 최대 득표수를 기준으로 자동 조정됩니다. 후보 색상은 고정입니다. 동점은 공동 1위로 표시하고 기존 막대 순서를 유지합니다.

## 개발 및 영상 제작 준비

독립적인 정적 화면으로 기존 투표 앱, 운영 DB, 배포 설정을 사용하지 않습니다. 외부 요청과 CDN은 없습니다. 폰트는 공식 A2Z v1.001 WOFF2를 포함하고 있으며 `fonts/OFL.txt`에 라이선스를 제공합니다.

검증: `node --test ceremony/tools/verify.cjs` (저장소 루트에서 실행).
원자료 갱신: `python ceremony/tools/import-votes.py <원본 엑셀 경로>` (openpyxl 필요, 집계값 검증 포함).
배포 ZIP: `python ceremony/tools/package.py`.

라이브 재생과 영상용 프레임은 같은 1920×1080 Canvas 렌더러를 사용합니다. `OSCAPlayback.renderAt(house, stage, seconds)`로 특정 부문·집계 구간 프레임을 재현할 수 있습니다. `renderWinner(house, seconds)`는 수상 장면입니다. 애니메이션은 60fps 기준의 결정적 타임라인이며, MP4 생성 작업은 다음 제작 단계입니다. 현재 패키지에는 MP4가 포함되지 않습니다.

개발 확인은 로컬 HTTP 미리보기에서 진행했습니다. Codex 내장 브라우저는 file:// 열기를 제한하므로 파일 직접 실행의 최종 리허설은 행사 PC의 Chrome/Edge에서 진행하세요. 듀얼 모니터와 행사장 음향도 실제 장비에서 확인하세요.
